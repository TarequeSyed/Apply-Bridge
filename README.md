# ApplyBridge — The "Ctrl+V" Opportunity Engine

> **Devpost Hackathon Submission:** Ctrl+V Hackathon 2026  
> **Theme:** Making Access Easier — Removing barriers to opportunities, education, and career mobility using AI & technology.  
> **Live Architecture:** Zero-Knowledge, 100% Client-Side Local-First SPA (IndexedDB + Direct Gmail API OAuth PKCE + Client-Side AI).  
> **Design Schematic:** High-Precision Bento Grid & Functional FinTech/SaaS Minimalism.

---

## 🚀 Quickstart Guide

```bash
# 1. Install dependencies
npm install

# 2. Start local development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.
